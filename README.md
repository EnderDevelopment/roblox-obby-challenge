# ObbyChallenge

ObbyChallenge is a Roblox script designed to create an obstacle course (obby) with start, finish, and obstacle platforms. It includes features like a leaderboard to track player times, player data storage for best times, and automatic respawning. The script is easy to set up and customize for various obby challenges.

## Install

1. Download the ObbyChallenge script files from the GitHub repository.
2. Open your Roblox Studio and create a new game or open an existing one.
3. Insert the script files into the appropriate parts in your game:
   - `StartPlatformScript.lua` into the Start Platform part.
   - `ObstacleScript.lua` into each Obstacle part.
   - `FinishPlatformScript.lua` into the Finish Platform part.
   - `LeaderboardScript.lua` into a Script in ServerScriptService.
   - `PlayerDataScript.lua` into a Script in ServerScriptService.
   - `RespawnScript.lua` into a Script in ServerScriptService.

## Use

1. Create a Start Platform and a Finish Platform in your game.
2. Add obstacles between the Start and Finish Platforms.
3. Ensure each part has the appropriate script inside it.
4. Test your obby by playing the game. Players will automatically respawn after dying, and their times will be recorded in the leaderboard.
